Find the needle, then see why it matters

Open the Detections menu to see every rule that matched, grouped by MITRE ATT&CK tactic and colored by severity. Pick one to filter the log to its hits.

  • Credential access: Kerberoasting, AS-REP roasting, password spraying, DCSync, LSASS access
  • Defense evasion: cleared logs, disabled auditing, Defender and firewall tampering, AMSI bypass
  • Lateral movement: PsExec and Impacket, pass-the-hash, RDP tunnelling, admin-share abuse
  • Thresholds that match real tooling: e.g. more than 10 accounts failing from one IP in 24 hours
  • Credit where it's due: rules adapted from Sigma and Hayabusa show their original authors

A query language made for event logs

Type in the search box; every term must match. Field names work with or without their full path.

mimikatzAny field contains the word
"logon type" -svchostExact phrase, excluding events that mention svchost
id=4769 TicketEncryptionType=rc4-hmacKerberos service tickets using RC4 (decoded values work too)
id=4624 LogonType=10 -IpAddress~"^10\."RDP logons from outside 10.0.0.0/8
process~"\\powershell\.exe$" CommandLine:-encEncoded PowerShell in Sysmon or Security process events

Install in a minute

One download. No Rust, Homebrew or terminal needed.

  1. Download Tidewatch.dmg and open it.
  2. Drag Tidewatch onto the Applications folder.
  3. Open Tidewatch, then double-click any .evtx file or drag it onto the window.
First launch: Tidewatch isn't notarized by Apple yet, so macOS may say it can't verify the developer. Click Done, then go to System Settings → Privacy & Security and click Open Anyway. You only need to do this once.
