Find the needle, then see why it matters

Open the Detections menu to see every rule that matched, grouped by MITRE ATT&CK tactic and colored by severity. Pick one to filter the log to its hits.

  • Credential access: Kerberoasting, AS-REP roasting, password spraying, DCSync, LSASS access
  • Defense evasion: cleared logs, disabled auditing, Defender and firewall tampering, AMSI bypass
  • Lateral movement: PsExec and Impacket, pass-the-hash, RDP tunnelling, admin-share abuse
  • Thresholds that match real tooling: e.g. more than 10 accounts failing from one IP in 24 hours
  • Credit where it's due: rules adapted from Sigma and Hayabusa show their original authors

Install in a minute

One command. No Rust, Homebrew or build tools needed, and no security prompts.

  1. Open Terminal (press ⌘ Space, type Terminal, press Return).
  2. Paste this and press Return:
    curl -fsSL https://nyanites.github.io/tidewatch/install.sh | bash
  3. Open Tidewatch from Launchpad or Applications, or double-click any .evtx file.
What the command does: downloads the latest release from GitHub, checks it against the published SHA-256 checksum, and copies Tidewatch into Applications. It never asks for your password. Read the script before running it if you like. After that, Tidewatch updates itself from Help → Check for Updates…. To uninstall, drag Tidewatch from Applications to the Trash.

Frequently asked questions

How do I open an EVTX file on a Mac?

macOS can't open Windows .evtx event logs on its own. Install Tidewatch, then double-click any .evtx file or drag it onto the Tidewatch window. It reads Security, System, Application, Sysmon, PowerShell and any other Windows event log natively, with no Windows VM.

Is there a Windows Event Viewer for Mac?

Microsoft's Event Viewer only runs on Windows. Tidewatch is a native macOS alternative: it shows every event and field like Event Viewer, and adds fast search, threat detections and Sigma rules.

Can Tidewatch handle very large event logs?

Yes. In our benchmark a 3.9 GB log with 5,039,642 events opened in 18 seconds, every search took about 40 ms, and 2,452 detection rules ran in under a second on an Apple M4 Pro.

Does Tidewatch support Sigma rules?

Yes. Point it at a folder of Sigma rules, such as the SigmaHQ repository, and about 2,400 Windows detections run alongside the 49 built-in rules, mapped to MITRE ATT&CK.

Does Tidewatch upload my logs anywhere?

No. Everything runs locally on your Mac: no uploads, no telemetry and no account. The source code is public on GitHub so you can verify it. The only network request Tidewatch makes is a once-a-day check of GitHub for a newer version, which sends nothing about you or your logs and can be turned off.

Is Tidewatch free?

Tidewatch is free for small teams: organizations with fewer than 100 people and under US$1M in revenue, under the PolyForm Small Business License. Larger organizations need a commercial license.

Does Tidewatch run on Windows or Linux?

Tidewatch runs on macOS 11 or newer, on Apple Silicon and Intel Macs. A Windows version is coming soon.
